1. היקף

מדיניות זו חלה על:

  • לקוחות הרוכשים Page Pack / Site Care או מבקשים הקמה;
  • מבקרים הצופים או שולחים הצעות בדפי הצעות של לקוחות שאנו מארחים, מספקים או מסייעים להפעיל;
  • מבקרים ב־suggestpage.com ובדפי הדגמה קשורים שאנו מפעילים (לדוגמה, הדגמות המקושרות מאתר המוצר).

אתרי לקוחות עשויים גם להיות מתארחים בתשתית של הלקוח (לדוגמה, GitHub Pages). כאשר לקוח שולט באופן עצמאי באירוח ובטפסים, אותו לקוח עשוי להיות אחראי עצמאי לנתוני המבקרים; מדיניות זו מתארת את הנוהגים שלנו כאשר אנו מעבדים נתונים כמפעיל Suggest Page / Color It Company.

2. מידע שאנו אוספים

2.1 לקוחות (רוכשים)

אנו עשויים לאסוף:

  • נתוני זהות ויצירת קשר: שם, כתובת דוא״ל, שם מותג/חברה, דומיין או URL, מספר טלפון אם סיפקתם, כתובת למשלוח דואר אם סופקה;
  • נתוני הקמה: מטרה בשורה אחת, העדפות מותג והוראות קשורות שאתם שולחים לנו;
  • נתוני חיוב: סטטוס תשלום, סוג תוכנית, חשבוניות ומטא־נתוני תשלום מוגבלים. תשלומי כרטיס מעובדים על ידי Stripe. איננו מקבלים את מספר הכרטיס המלא כאשר Stripe Checkout פועל כמתוכנן; Stripe הוא מעבד תשלומים עצמאי. ראו את מדיניות הפרטיות של Stripe;
  • תקשורת: דוא״ל, הודעות צ׳אט ותכתובת תמיכה;
  • נתוני תפעול השירות: הערות פרסום/טריאז׳, החלטות Yes/Later/No שאנו מסייעים ליישם במסגרת Site Care.

2.2 מבקרים ששולחים הצעות

טפסי Suggest Page טיפוסיים שולחים הגשות דרך ספק משלוח טפסים (כיום Web3Forms) לדוא״ל התפעולי. אנו (ו/או הלקוח, בהתאם לתצורה) עשויים לקבל:

  • טקסט הרעיון (תוכן הצעה נדרש);
  • שדות אופציונליים — שם, דוא״ל ו/או URL של הדף כאשר הטופס כולל אותם;
  • מטא־נתונים טכניים / תפעוליים — מזהה אתר מוסתר, זמן הגשה ומטא־נתונים של מטפל הטפסים;
  • משואות קישור החלטה — כאשר מפעיל לוחץ על קישור חתום Yes / Later / No, Web3Forms עשוי לקבל מזהה אתר, מזהה הצעה, פעולה וטוקן לטריאז׳ (לא התחברות של מבקר).

לוח ציבורי: רעיונות מאושרים ובסטטוסים אחרים עשויים להתפרסם בקבצים סטטיים (לדוגמה suggestions/data.json ב־GitHub Pages), שיכולים לכלול טקסט הצעה, שם אופציונלי, דף, סטטוס, הערות ותאריכים.

איננו דורשים ממבקרים ליצור חשבון או להתחבר כדי לשלוח הצעה.

2.3 נתונים שנאספים אוטומטית (מבקרים באתר)

באתרים שבשליטתנו (כגון suggestpage.com), אנו עשויים לאסוף:

  • יומני שרת או CDN סטנדרטיים (כתובת IP, סוג דפדפן, URL מפנה, חותמות זמן);
  • עוגיות / אחסון מקומי כמתואר בהודעת העוגיות.

אנליטיקה (לאישור): אנו עשויים להשתמש בעוגיות חיוניות ובכלי אנליטיקה אופציונליים. הספקים המדויקים רשומים כפריטים פתוחים ב־README המשפטי עד לאישור.

2.4 מידע שאיננו אוספים בכוונה

איננו אוספים בכוונה מספרי זיהוי ממשלתיים, PAN של כרטיסי תשלום או נתוני בריאות מקטגוריה מיוחדת דרך טפסי Suggest Page. אנא אל תשלחו מידע אישי רגיש בטקסט ההצעות.

3. כיצד אנו משתמשים במידע

אנו משתמשים במידע כדי:

  • לספק, להקים ולתחזק את Suggest Page ו־Site Care;
  • לעבד תשלומים ולמנוע הונאה (עם Stripe);
  • לשלוח התראות על רעיונות והודעות תפעוליות בדוא״ל;
  • לעדכן לוחות ציבוריים (לדוגמה באמצעות data.json ופרסום מחדש) לפי החלטות Yes / Later / No;
  • לתקשר על הזמנות, חידושים, ביטולים ותמיכה;
  • לשפר את המוצר והתיעוד;
  • לציית לחוק, לאכוף את התנאים ומדיניות השימוש המקובל, ולהגן על זכויות ובטיחות.

4. כיצד אנו משתפים מידע

אנו עשויים לשתף מידע עם:

  • Stripe — עיבוד תשלומים באמצעות Stripe Payment Links / Checkout / Customer Portal (נתוני הכרטיס נשארים אצל Stripe);
  • Web3Forms — משלוח טפסים ומשואות קישור החלטה לדוא״ל טריאז׳ של הצעות;
  • אירוח / CDN — לדוגמה GitHub Pages לקבצי אתר סטטי;
  • ספקי דוא״ל ותשתית — למשלוח הודעות ולאירוח או פריסת אתרים סטטיים;
  • אוטומציה פנימית — בוטים של צוות או מפעילים עשויים לקרוא דוא״ל טריאז׳ ולעדכן את הלוח הציבורי; אין מוצר AI גנרטיבי הפונה למשתמש בדפים עצמם;
  • לקוחות — תוכן הצעות מבקרים שנשלח בדף של אותו לקוח מסופק ללקוח כדי שיוכל להפעיל את הלוח;
  • ספקי שירות המסייעים תחת התחייבויות חוזיות (אירוח, DNS, קבלנים העובדים על Site Care);
  • משפטי / בטיחות — כאשר נדרש בחוק, או להגנה על זכויות, אבטחה ושלמות;
  • העברת עסק — בקשר למיזוג, מכירה או ארגון מחדש, בכפוף להגנות מתאימות.

איננו מוכרים מידע אישי תמורת כסף. איננו „משתפים“ ביודעין מידע אישי לפרסום התנהגותי חוצה־הקשר כפי שמונחים אלה משמשים ב־California Consumer Privacy Act (CCPA/CPRA), אלא אם נעדכן מדיניות זו ונציע את הבחירות הנדרשות.
