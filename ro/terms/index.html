2. Serviciul

2.1 Suggest Page (Page Pack)

Suggest Page este un produs care livrează pagini statice de sugestii pentru marca sau proiectul dvs., inclusiv un panou public care poate afișa ideile vizitatorilor marcate Yes, Later sau No.

Flux tipic:

  1. Un vizitator trimite o idee pe pagina dvs. de sugestii.
  2. Ideea este trimisă pe e-mail către dvs. (și/sau către noi, după configurație).
  3. Dvs. (sau noi, în cadrul Site Care) marcați ideea Yes / Later / No.
  4. Panoul public se actualizează din datele site-ului (de exemplu, un fișier data.json) când site-ul static este republicat.

Păstrați fișierele statice. Configurația este concepută să fie compatibilă cu GitHub Pages (sau găzduire statică similară). Produsul, așa cum este descris în general, nu necesită un perete de autentificare pentru vizitatori.

2.2 Site Care

Site Care este un nivel opțional de serviciu care poate include triaj lunar și modificări mici din ideile pe care le-ați marcat Approved (sau echivalent Yes/aprobat), sub rezerva excluderilor din Secțiunea 2.3 și a oricărei descrieri a planului pe site sau la checkout.

2.3 Excluderi Site Care

Site Care nu include, decât dacă convenim altfel în scris:

  • Reproiectări complete

  • Aplicații personalizate sau dezvoltare continuă
  • Asistență continuă prin chat cu vizitatorii
  • Rescrieri sau reproiectări mari nelimitate

Putem refuza sau cotiza separat lucrările în afara acestor limite.
