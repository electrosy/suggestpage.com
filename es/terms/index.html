2. El servicio

2.1 Suggest Page (Page Pack)

Suggest Page es un producto que entrega páginas estáticas de sugerencias para su marca o proyecto, incluido un tablero público que puede mostrar ideas de visitantes marcadas como Yes, Later o No.

Flujo típico:

  1. Un visitante envía una idea en su página de sugerencias.
  2. La idea se envía por correo electrónico a usted (y/o a nosotros, según la configuración).
  3. Usted (o nosotros, bajo Site Care) marca la idea Yes / Later / No.
  4. El tablero público se actualiza a partir de los datos del sitio (por ejemplo, un archivo data.json) cuando el sitio estático se vuelve a publicar.

Usted conserva los archivos estáticos. La configuración está pensada para ser compatible con GitHub Pages (u hospedaje estático similar). El producto, tal como se describe generalmente, no exige un muro de inicio de sesión para los visitantes.

2.2 Site Care

Site Care es un nivel de servicio opcional que puede incluir triaje mensual y ediciones menores a partir de ideas que usted haya marcado como Approved (o el equivalente Yes/aprobado), sujeto a las exclusiones de la Sección 2.3 y a cualquier descripción del plan en el sitio o en el proceso de pago.

2.3 Exclusiones de Site Care

Site Care no incluye, salvo acuerdo escrito en contrario:

  • Rediseños completos
  • Construcciones multipágina más allá del entregable de Suggest Page
  • Aplicaciones personalizadas o desarrollo continuo
  • Soporte continuo de chat con visitantes
  • Reescrituras o rediseños grandes ilimitados

Podemos rechazar o cotizar por separado el trabajo fuera de estos límites.

2.4 Configuración

Tras el pago, pretendemos configurar su página en un plazo de 24 horas. Normalmente pedimos:

  • La URL o el dominio que desea usar
  • Nombre de marca / nombre para mostrar
  • Un propósito o descripción en una línea

Pueden producirse retrasos si no proporciona a tiempo la información necesaria.
