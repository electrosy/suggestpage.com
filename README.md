# suggestpage.com

Static GitHub Pages site.

- `/` — product story; primary buy CTA is `/sell/`
- `/sell/` — commercial conversion page (Stripe Payment Links)
- `/sell/thanks/` — post-purchase page (`noindex`; Stripe success URL)
- `/suggest/` and `/suggestions/` — live Web3Forms demo
- `/es/`, `/ro/`, `/he/`, `/tr/` — locale path prefixes for legal pages
- Language switcher: EN / ES / RO / HE / TR (`js/i18n.js`, `js/legal-lang.js`)

Crawl: `/robots.txt` → `/sitemap.xml`. Share image: `/images/og.png`.
